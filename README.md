# TALEBLOCKS V1

A responsive, cinematic one-page website for TALEBLOCKS.

## Files
- `index.html` — main website
- `style.css` — visual design and responsive layout
- `script.js` — navigation and scroll animations
- `assets/taleblocks-logo.png` — your uploaded logo

## Run locally
Open `index.html` in a browser.

For the cleanest local preview, use a simple local server:
- VS Code + Live Server, or
- any static HTTP server.

## Publish for free
This is a static website, so it can be hosted on free static hosting such as GitHub Pages or Cloudflare Pages.

## Before publishing
Open `index.html` and replace the placeholder `#` links for YouTube and Instagram with your real profiles. Change the email address if needed.

## Notes
Google Fonts are loaded from the web. The site still works without them by falling back to Georgia/Arial.
